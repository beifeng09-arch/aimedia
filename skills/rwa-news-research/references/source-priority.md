# Source Priority

Use sources in this order when available:

1. official issuer, institution, regulator, or project announcement
2. primary interview, filing, or attributed statement
3. mainstream reporting with clear attribution
4. niche industry coverage with verifiable sourcing
5. market chatter or social summaries only as weak-signal context

If multiple articles describe the same event, keep the highest-priority source and use lower-priority coverage only to fill missing context.
